# APT Validation Reports Directory

This folder stores portfolio-level outputs generated by APT validation and sweep scripts.

## What Is Here

- `project-profile-validation-sweep-YYYY-MM-DD.json`: machine-readable workspace summary.
- `project-profile-validation-sweep-YYYY-MM-DD.md`: human-readable dashboard summary.
- `GRAPHIFY_RUNBOOK.md`: operator workflow for building and querying the APT-wide Graphify knowledge graph.
- `graphify-apt-gap-analysis-YYYY-MM-DD.md`: curated Graphify gap analysis reports.
- `apt-principles-framework-audit.md`: framework-level audit findings and remediation status.

## How To Generate

From `apt-principles`:

```bash
# Doctrine and structure validation
npm run validate

# AI configuration readiness (scores 0–4, reports gaps)
npm run validate:ai

# AI skill sync check across .github/, .claude/, .codex/
npm run sync:check

# Full check suite (validate + sweep + sibling repo quality)
npm run run-all-checks

# Project profile sweep across all workspace repos
npm run sweep:project-profiles

# Graphify knowledge graph
npm run graphify:check
npm run graphify:apt
npm run graphify:gaps
```

To write an AI readiness report for a downstream project:

```bash
node scripts/validate-ai-readiness.mjs --repo-root ../apt-coach --report
```

Output is written to `apt-coach/docs/apt/reports/ai-readiness-YYYY-MM-DD.md`.

To scaffold missing AI config first, then report:

```bash
node scripts/validate-ai-readiness.mjs --repo-root ../apt-coach --fix
node scripts/validate-ai-readiness.mjs --repo-root ../apt-coach --report
```

Use `npm run run-all-checks` when you want one operator command that runs canonical validation, sweep generation, and selected repo quality checks before printing a compact pass/fail summary.

Optional:

```bash
npm run sweep:project-profiles -- --date YYYY-MM-DD
npm run sweep:project-profiles -- --repos repo-a,repo-b
npm run sweep:project-profiles -- --workspace-root ../
```

## How To Use The Results

1. Read the markdown report first to triage by severity, APT layer, and action queue.
2. Open the JSON report to automate follow-up (issue creation, dashboards, trend checks).
3. For any repo-specific deep dive, open that repo's local static report at `docs/apt/reports/static/project-profile-validation-sweep-YYYY-MM-DD.json`.
4. Use Graphify reports to find cross-repo doctrine/code drift candidates, then convert only source-supported findings into remediation work.
