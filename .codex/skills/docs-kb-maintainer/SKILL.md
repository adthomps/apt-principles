# Docs KB Maintainer

<!-- Canonical source: .github/skills/docs-kb-maintainer/SKILL.md — sync when updating -->

## Purpose

Create or update practical documentation for developers and operators.

## Required steps

1. Identify the documentation type: README, API reference, migration guide, KB article, deployment runbook.
2. Read existing docs in the same folder to match style and format.
3. Use clear headings, short paragraphs, and step-by-step instructions.
4. Include a troubleshooting section when relevant.
5. Add examples and commands where applicable.
6. Update the doc when the behavior it describes has changed.

## Rules

- Do not over-market or use vague superlatives.
- Be direct about limitations and known issues.
- Keep examples realistic and runnable.
- Use Mermaid diagrams when a visual helps understanding.

## Completion report

Return:

1. Files created or updated
2. Sections added or changed
3. Known gaps or items deferred
