\# Implement Feature Prompt



Implement the requested feature using the repository's existing conventions.



Required process:



1\. Inspect repo structure.

2\. Read `AGENTS.md`.

3\. Identify package manager.

4\. Identify affected files.

5\. Make the smallest safe change.

6\. Add or update tests.

7\. Update docs when behavior changes.

8\. Run validation.

9\. Report results.



Do not:



\- Add new dependencies without explaining why.

\- Change unrelated files.

\- Remove existing behavior without documenting it.

\- Claim validation passed unless it actually passed.
