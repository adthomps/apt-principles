# Portfolio UI Kit Reference

## Context

This vendored kit demonstrates the APT portfolio surface with cosmic background, hero identity, Labs/Proof cards, route-aware navigation, and footer treatment.

## Problem

Portfolio surfaces can become generic marketing pages that hide what is built, proven, experimental, or reusable.

## APT Principles Applied

- Design: clear identity and proof-oriented structure.
- Release: public pages should distinguish demos, prototypes, and stable proof.
- Knowledge: portfolio items should connect to reusable patterns and evidence.

## Solution

Open `index.html` to inspect the portfolio composition. It shows the AptEmblem, cosmic background, concise hero copy, card hierarchy, Labs/Proof organization, and compact footer.

Use `../../../product-portfolio-surface-pattern.md` as the canonical example that interprets this kit.

## Tradeoffs

The pattern is intentionally restrained compared with a high-gloss marketing site. It favors evidence and identity over spectacle.

## Common Mistakes

- Hero copy with no concrete offer or proof.
- Project cards without status or source context.
- Overusing glow, glass, or accent color as decoration.
