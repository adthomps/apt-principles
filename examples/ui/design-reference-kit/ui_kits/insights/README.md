# Insights UI Kit Reference

## Context

This vendored kit demonstrates an APT content surface for articles, podcasts, case studies, filters, cover cards, and reading views.

## Problem

Content surfaces can turn into promotional grids with vague metadata, weak filters, and imagery that competes with the actual learning.

## APT Principles Applied

- Thinking: content should clarify decisions and learning.
- Design: metadata and hierarchy support scanning.
- Knowledge: reusable learning should be findable.

## Solution

Open `index.html` to inspect the insights surface. It includes content cards, filters, metadata, cover treatments, and a reading/detail view that preserves APT's calm technical voice.

Use `../../../content-insights-card-pattern.md` as the canonical example that interprets this kit.

## Tradeoffs

The pattern asks authors to maintain useful metadata. That work improves browsing and reduces decorative content drift.

## Common Mistakes

- Using cover imagery as the main information source.
- Creating tags that do not map to browsing decisions.
- Writing marketing copy instead of evidence-oriented summaries.
