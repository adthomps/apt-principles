# Product UI Kit Reference

## Context

This vendored kit demonstrates an APT product landing surface with cosmic hero, feature grid, stats, pricing tiers, testimonial, and call to action.

## Problem

Product pages can over-index on sales language and decorative layouts instead of showing what the system does and why it can be trusted.

## APT Principles Applied

- Thinking: product pages should clarify the offer and audience.
- Design: hierarchy and proof should guide the page.
- Release: public claims should be supported by evidence or status notes.

## Solution

Open `index.html` to inspect the product landing composition. It demonstrates the APT brand shell, product offer, feature grouping, stats, pricing interaction, testimonial treatment, and final CTA.

Use `../../../product-portfolio-surface-pattern.md` as the canonical example that interprets this kit.

## Tradeoffs

The product pattern has more conversion structure than doctrine or docs pages. Keep the voice precise so it does not become generic marketing.

## Common Mistakes

- Multiple competing calls to action.
- Pricing or proof claims without status or context.
- Accent color used as the default CTA or hover color.
