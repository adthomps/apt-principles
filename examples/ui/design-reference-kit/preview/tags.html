Does teal fit APT principles? Yes — but narrowly. The shipped AptTag exposes only blue/neutral variants, so type & status badges default to blue. Teal is permitted only for success treatment, section identity, and chart accents. Using it as a generic tag, CTA, hover, or active-nav color is a lint-critical failure.
