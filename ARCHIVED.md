# Frozen Historical Mirror

This repository was frozen on 2026-06-28 and is retained as a public historical
mirror. It accepts no active development, fixes, releases, or support requests.

- Maintainer source: [apt-principles-agents](https://github.com/adthomps/apt-principles-agents)
  (private; access is limited to maintainers).
- Public documentation: [generated APT docs](https://appliedpracticalthinking.com/docs/apt/README.md).
- Final snapshot tag: `archive-final-2026-06-28`.

Existing scripts, documents, releases, issues, and Git history are preserved as
historical evidence. They describe the former split-ownership model and must not
be used as the current installation or contribution interface.

The GitHub repository intentionally remains unarchived so its public historical
content stays easy to browse. This does not indicate that development is active.
