\# Docs KB Maintainer

\## Purpose



Create practical documentation for developers, support teams, and operators.



\## Use this skill when



The user asks to:



\- Write a README

\- Update docs

\- Create a migration guide

\- Create a support KB

\- Explain an API

\- Create troubleshooting docs

\- Create diagrams

\- Document deployment



\## Documentation style



Prefer:



\- Clear headings

\- Short paragraphs

\- Step-by-step instructions

\- Tables for comparison

\- Examples

\- Troubleshooting sections

\- Known limitations

\- Mermaid diagrams when useful
