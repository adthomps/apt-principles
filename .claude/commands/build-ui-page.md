\# Build UI Page



Build or update a React TypeScript UI page.



\## Instructions



1\. Inspect the existing UI structure.

2\. Reuse existing layout, components, tokens, and route patterns.

3\. Use TypeScript.

4\. Use accessible HTML.

5\. Include:

&#x20;  - Loading state

&#x20;  - Empty state

&#x20;  - Error state

&#x20;  - Responsive layout

6\. Keep data fetching separate from rendering where the existing architecture allows.

7\. Do not add a new UI library without approval.

8\. Add or update tests where applicable.



\## Preferred page pattern



Use summary-to-detail structure:



\- List view

\- Filter/search controls when useful

\- Detail page or detail panel

\- Related records

\- Clear actions



\## Required output



Return:



1\. UI summary

2\. Files changed

3\. Components added

4\. States handled

5\. Tests added or skipped

6\. Validation results
