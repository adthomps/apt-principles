\# Add API Route



Add or update an API route using the project’s existing conventions.



\## Instructions



1\. Inspect existing API routes first.

2\. Identify the routing framework.

3\. Follow the existing file organization.

4\. Define the API contract before implementation.

5\. Validate input before business logic.

6\. Use consistent error handling.

7\. Add tests.

8\. Update docs or OpenAPI files if present.

9\. Run validation commands.



\## Required output



Before editing, summarize:



\- Endpoint path

\- HTTP method

\- Request body

\- Response body

\- Error cases

\- Files likely impacted



After editing, summarize:



\- Files changed

\- Tests added

\- Validation commands run

\- Known limitations
